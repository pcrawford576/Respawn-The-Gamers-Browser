# Respawn changelog

Write notes for the next build under "Unreleased" (one "- " line per change).
release.ps1 turns them into the new version's notes when you build.

## Unreleased
- New name: Respawn, The Gamers Browser, with the new logo and the tagline on the new-tab page and window title.
- Respawn is now open source (MIT license) and releases are built on GitHub, ready for free code signing through SignPath.
- Installer description no longer mentions picture-in-picture.

## 0.1.2 - 2026-11-08
- New green-glow Respawn logo for the app icon, installer, tab bar, new-tab page and Android launcher.
- Full-screen game view: press F12 (or the new Full screen button) to hide every bar so the game fills your screen. Esc also leaves full screen.
- Full-screen account badge: shows which account you're viewing; click it to switch to any saved account or open tab.
- Keyboard shortcuts can now be changed in Settings → Keyboard shortcuts, and they work inside games too.
- Screen capture & markup (camera button or Ctrl+Shift+X): pen, highlighter, lines, arrows, boxes, clouds, text, callouts, count markers, redact and crop.
- Markup snapping to corners, endpoints, midpoints and centres; Shift keeps lines horizontal or vertical.
- Discord: servers and channels stay in the Chat sidebar and the conversation opens in one tab. Right-click a server, channel or link → Open in new tab.
- DeepL translator for Discord chat: translations under foreign messages, Alt+T translates what you type. Add your DeepL key in Settings.
- Saved accounts: name a tab to keep its login, and reopen it from Accounts ▾ even after closing the tab.
- Version number shown in Settings, and these "What's new" notes after each update.
- Removed picture-in-picture.

## 0.1.0 - 2026-11-07
- First release of Respawn: a lightweight browser for gamers.
- Tabs that hibernate in the background so games stay loaded, with "Keep loaded" pins.
- Separate login per tab, so several tabs can play different accounts; rename tabs and drag to reorder them.
- Q / W to switch tabs, even inside games.
- Game Mode (Ctrl+Shift+G), ad & tracker blocker, gaming sidebar (Discord, Twitch, YouTube, Steam).
- Address-bar autofill from your history, tabs restored on restart, automatic reload after game crashes.
- Guided feature tour (? button).
